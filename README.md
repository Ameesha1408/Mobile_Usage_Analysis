# Mobile_Usage_Analysis
Analysis of mobile usage data using Python

## Project Overview
This project analyzes mobile usage data to understand user behavior patterns.
The analysis is performed using Python and focuses on usage trends, activity levels,
and insights that can support data-driven decisions.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

## Project Files
- mobile_usage_Project.ipynb – Main analysis notebook

## Key Analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Visualization of mobile usage trends
- Insight generation based on patterns

## How to Run
1. Clone the repository
2. Open the notebook in Jupyter
3. Run cells sequentially
